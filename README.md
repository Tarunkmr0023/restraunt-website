# Chicken Point – Restaurant Website

Website for Chicken Point, a chicken restaurant in Shiv Vihar, Karawal Nagar, Delhi. Built with React and Vite, focused on getting visitors to order by WhatsApp, Zomato or phone.

**Live:** https://chickenpoint.netlify.app

## Tech Stack

- Vite 7
- React 18
- React Router v6
- Framer Motion (page transitions and scroll reveals)
- MUI icons only (styling is plain CSS in `src/index.css`)
- Netlify (deployment)

## Features

- Modern design: floating glass header, full-screen hero, rounded cards, orange gradient on a warm dark/light palette
- Menu with category tabs and a Quarter / Half / Full portion selector per dish
- Every dish has an **Order on WhatsApp** button (pre-filled message) and an **Order on Zomato** button
- Floating Call / WhatsApp / Zomato bar on mobile
- Live open/closed badge in the hero (6 PM to 11 PM IST, closed on Tuesdays)
- Free delivery note: within 1 km, minimum order Rs 300
- Pages: Home, Menu, Our Story, Find Us (with embedded Google Map)
- SEO: page title and description, Open Graph tags, and `Restaurant` structured data (address, hours, phone)
- Lazy-loaded routes and scroll-to-top on navigation

## Getting Started

```bash
npm install      # first time only
npm run dev      # http://localhost:5173
```

```bash
npm run build    # production build in dist/
npm run preview  # preview the production build
```

## Project Structure

```
index.html                  # meta tags, fonts, structured data
public/logo.svg             # logo and favicon
src/
  index.css                 # design system and all styles
  data/business.js          # phones, address, hours, links, open/closed logic
  data/data.js              # menu items, prices, categories, REVIEWS
  components/
    DishCard.jsx            # menu card with portion selector and order buttons
    Reveal.jsx              # scroll-in animation wrapper
    Layout/                 # Header, Footer, Layout (mobile order bar)
  pages/                    # Home, Menu, About, Contact
  images/                   # dish and banner photos
```

## Updating Content

- **Prices, dishes, categories, tags:** edit `src/data/data.js`
- **Phone numbers, address, hours, Zomato/WhatsApp/Maps links, closed day:** edit `src/data/business.js`
  (also update the opening hours in the structured data in `index.html`)
- **Customer reviews:** add real reviews to `REVIEWS` in `src/data/data.js`. The reviews section on the home page appears only when the list has entries.
- **Photos:** replace files in `src/images/` keeping the same names, or update the imports in `src/data/data.js`

## Deployment

`dist/` is generated by `npm run build` and is not committed (it is in `.gitignore`). Netlify builds the site with `npm run build` and publishes `dist`.
