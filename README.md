# 🍗 Chicken Point – Restaurant Website

A modern, responsive restaurant website built using **React + Vite + Material UI**.  
This project showcases menu items, delivery information, contact details, and smooth animated transitions for a premium user experience.

🌐 **Live Demo:** https://chickenpoint.netlify.app  
---

## 🚀 Tech Stack

- ⚡ Vite
- ⚛️ React 18
- 🎨 Material UI (MUI)
- 🎞 Framer Motion (Page Animations)
- 🌐 React Router v6
- ☁️ Netlify (Deployment)

---

## ✨ Features

- ✅ Fully Responsive Design
- ✅ Smooth Page Transition Animations
- ✅ Lazy Loaded Routes (Performance Optimized)
- ✅ Scroll-to-Top on Route Change
- ✅ Premium Floating Delivery Banner
- ✅ Hover Animations & Glow Effects
- ✅ Modern Navbar UI with Active Highlight
- ✅ Splash Screen Animation
- ✅ SEO-Friendly Setup
- ✅ Click-to-Call Support for Mobile
